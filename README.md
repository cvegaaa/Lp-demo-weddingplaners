# Maison Lumière — Landing de Wedding Planner

Landing page demo para un wedding planner de bodas y eventos de lujo.

## Qué resuelve

Presenta servicios de organización de bodas de alta gama con galería, testimonios y formulario de contacto orientado a agendar una consulta.

## Stack técnico

- React + TypeScript + Vite
- Tailwind CSS
- Supabase (formulario de contacto)

## Estado

Demo de portafolio.
